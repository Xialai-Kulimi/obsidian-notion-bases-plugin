# 日曆互動改版：需求文件

狀態：**需求與設計已確認，待使用者審閱本文件後撰寫實作計畫**（2026-09-19）
範圍：Notion Bases Custom（fork 自 bgarciamoura/obsidian-notion-bases-plugin）

## 1. 背景

使用者透過 iCloud 同步 vault，並在電腦、手機、平板使用 Obsidian。目前日曆檢視有幾個操作上的問題：
點擊日期會「立刻」建立檔案（容易誤觸）、點擊卡片會「立刻」開啟檔案、週檢視無法指定時間建立、也不能拖曳調整時間。
另外，介面的中文是簡體，需要改成繁體。

## 2. 需求清單

編號之後會沿用到計畫與測試，請以編號討論。

### R0　介面語系改為繁體中文

- 現況：[src/i18n/locales/zh.ts](../../../src/i18n/locales/zh.ts) 是**簡體**，且 `zh` 與 `zh-TW` 兩個語系代碼都指向它（[src/i18n/index.ts](../../../src/i18n/index.ts)）。
- 需求：使用者看到的所有介面文字為繁體中文，用詞採台灣慣用語（例：视图→檢視、字段→欄位、文件→檔案）。
- 之後新增的字串（R1～R6）必須同時提供 `en` 與繁體中文版本，其他語系依現有機制退回英文。

### R1　月／週檢視：點擊日期改為「行內輸入後才建立」

- 現況：[DatabaseCalendar.tsx:336](../../../src/components/DatabaseCalendar.tsx) 的 `handleDayClick` 點擊即建立檔案，檔名固定為「未命名」加序號。
- 需求：
  1. 點擊某天的空白處，在該處出現文字輸入框，預設內容為「未命名」（並全選，方便直接打字覆蓋）。
  2. 按 **Esc**：一律取消，不建立任何檔案（視為誤觸）。
  3. 按 **Enter**：以輸入的文字為檔名，建立 `.md`，並把日期欄位設為被點擊的那天。
  4. **失焦**（點到別處）：
     - 使用者**打過字**且內容不是空白 → 視為有建立意願，**建立**。
     - 輸入框被清空（或只剩空白）→ **不建立**。
     - 完全沒打字、維持預設「未命名」→ **不建立**（誤觸）。
  5. 輸入框為空（或只剩空白）時按 Enter → 不建立。
  6. 輸入法組字中的 Enter（選字）不算送出。
- 月檢視與週檢視（含「全天」列）行為一致。

### R2　週檢視：點擊時間段，在該時間建立

- 需求：在週檢視的時間格上點擊，於該時間建立檔案，日期欄位寫入含時間的值（例：`2026-09-21T14:00`）。
- 建立流程與 R1 相同（行內輸入、Esc 取消、Enter 建立）。
- 時間對齊到 15 分鐘（點擊位置向下取整到最近的 15 分鐘）。
- 點擊「全天」列則只寫入日期，不含時間（沿用現有的日期格式規則）。

### R3　週檢視：拖曳改變時間

- 需求：在週檢視拖曳卡片，可以改變**日期與時間**（現況只能改日期，時間保持不變）。
- 若設定了結束日期欄位，結束時間須一起平移，維持原有長度（延續現有 #58 的行為）。
- 時間對齊到 15 分鐘。
- 若同時選取了多張卡片，拖曳其中一張時全部一起移動（相同的日期與時間位移）。

### R4　卡片選取狀態

- 需求：
  1. 在日曆上「單擊」卡片：卡片進入被選取狀態（有明顯的視覺標示），**不會開啟檔案**。
  2. 「雙擊」卡片：開啟檔案。
  3. 單擊空白處：取消選取。
- 適用於月檢視、週檢視，以及「沒有日期」區塊的卡片。

### R5　刪除鍵刪除選取的檔案

- 需求：有被選取的卡片時，按下刪除鍵，刪除對應的 `.md`，**不跳確認**。
- macOS 的「delete」鍵實際上是 Backspace，兩者（Delete、Backspace）都要支援。
- 刪除走 Obsidian 的 `trashFile`（依使用者的 Obsidian「已刪除檔案」設定，進系統垃圾桶或 `.trash`），可復原。

### R6　多重選取

- 需求：可以同時選取多張卡片，R5 的刪除對全部選取的卡片生效。
- 選取手勢：Cmd／Ctrl + 點擊 加入或移除選取（已確認只做這個）。
- 選取多張後拖曳其中一張，所有選取的卡片一起移動（見 R3）。

## 3. 需求之間的依賴關係

```
R0  語系 ──────────────（獨立，但 R1～R6 新增的字串要同步翻譯）
R4  選取模型 ──┬── R6 多選（擴充 R4 的選取集合）
              └── R5 刪除（讀取 R4/R6 的選取集合）
R1  行內建立 ──── R2 時間段建立（R2 = R1 + 由點擊位置換算時間）
R2 ┐
   ├── 共用「Y 座標 ⇄ 分鐘」換算與對齊（snap）邏輯
R3 ┘
```

需要特別處理的交互作用：

| 交互 | 說明 | 暫定處理 |
|---|---|---|
| R1 × R4 | 點擊空白處同時代表「開始建立」與「取消選取」 | 兩者一起發生：清除選取並開啟行內輸入 |
| R1 × R5 | 在行內輸入框裡按 Backspace／Delete 是編輯文字，不能刪檔 | 鍵盤刪除只在「焦點不在輸入框」時生效 |
| R3 × R4 | 拖曳與單擊選取需區分，拖曳後不應留下誤選或誤開啟 | 拖曳起點的卡片自動加入選取 |
| R3 × R6 | 選取多張後拖曳其中一張 | **已確認**：一起移動，套用相同位移；被拖的那張若不在選取內，先單獨選取它 |
| R4 × 導覽 | 切換月／週或上下一頁後，看不見的卡片還被選取，Delete 會誤刪 | 導覽或切換檢視時清除選取 |
| R1 × 範本 | 資料庫若設定「建立時詢問範本」，會跳出範本選擇視窗 | 先輸入名稱（Enter）→ 再選範本 |
| R1 × 建檔 | `createNote` 目前不能指定檔名（固定「未命名」＋序號） | 新增 `title` 參數，處理非法字元與重名（沿用現有的重名後綴機制） |

## 4. 與現有程式碼相關的發現

- 日曆全部邏輯集中在 [DatabaseCalendar.tsx](../../../src/components/DatabaseCalendar.tsx)（977 行）。
- 週檢視每小時高度 48px，卡片以百分比定位；拖曳放下的處理函式 `handleDayDrop` 只改日期，保留原本的時間。
- 拖曳使用 HTML5 drag-and-drop。**手機與平板的觸控不支援**，月檢視在行動裝置上本來就關閉拖曳。
- 行動裝置目前用「長按日期 → 底部選單」來新增與操作檔案。
- 刪除已有 `DatabaseManager.deleteNotes()` 可重用；其他檢視（表格等）已有多選與刪除的實作，可參考其手勢風格。

## 8. 設計

### 8.1 整體做法

留在 `DatabaseCalendar.tsx` 內修改，不重寫成 Month／Week 兩個元件；把不依賴 Obsidian 的純邏輯抽到新檔以便單元測試。

### 8.2 純邏輯：`src/calendar-utils.ts`（新增，vitest 測試）

- `parseDateValue` / 日期值格式化：從元件搬出。
- `snapMinutes(min, step = 15)`：對齊到 15 分鐘。
- `yToMinutes(offsetY, columnHeight)`：滑鼠 Y 座標換算為當天分鐘數（0～1439）。
- `shiftDateValue(value, deltaDays, deltaMinutes)`：平移日期值，保留「純日期」或「含時間」的格式。
- `sanitizeTitle(raw, fallback)`：移除 Obsidian 檔名不允許的字元（`\ / : * ? " < > | # ^ [ ]`），前後空白修剪，結果為空則回傳 fallback。

### 8.3 選取、多選、刪除（R4、R5、R6）

- 新增 `useCalendarSelection`：以路徑集合保存選取；`click(path, additive)`、`clear()`；資料變動時移除已不存在的路徑；翻頁、切換月／週時清空。
- 卡片：`onClick` 選取（Cmd／Ctrl 為加入或移除）、`onDoubleClick` 開啟檔案；點擊事件需 `stopPropagation`，避免觸發格子的建立。
- 日曆容器 `tabIndex=0`，`onKeyDown` 收到 Delete 或 Backspace 且事件目標不是輸入框時，呼叫既有 `manager.deleteNotes()`，不跳確認。
- 選取樣式 `.nb-cal-card--selected`。
- 行動裝置沿用現況（點一下開啟、長按日期出選單），不套用選取邏輯。

### 8.4 行內建立（R1、R2）

- 元件狀態 `draft: { year, month, day, minutes: number | null } | null`，同一時間只有一個。
- 新增 `InlineCreateInput`：掛載時全選預設文字；記錄「是否輸入過」；依 R1 的規則處理 Enter、Esc、失焦；判斷輸入法組字中（`isComposing`）時忽略 Enter。
- 顯示位置：月檢視在日期格內；週檢視絕對定位在被點的時間位置（點擊 Y 座標 → `yToMinutes` → `snapMinutes`）；全天列在全天格內。
- `DatabaseManager.createNote` 與 `createNoteWithTemplate` 新增 `title` 參數（經 `sanitizeTitle`，重名沿用現有後綴機制）。日期（以及有設定結束欄位時的 +1 小時結束值）隨 `initialFrontmatter` 一次寫入，取代現在「先建檔、再改日期」的兩步驟。
- 若資料庫設定建立時詢問範本：Enter（或失焦建立）之後才跳出範本選擇。

### 8.5 週檢視拖曳（R3）

- 拖曳開始時記錄滑鼠在卡片內的 Y 偏移，放下時用日期欄位的 `getBoundingClientRect()`（欄位涵蓋完整 24 小時，捲動不影響）換算新時間並對齊 15 分鐘。
- 以「被拖曳卡片的舊值 → 新值」求出位移，用 `shiftDateValue` 同時套用到所有選取的卡片，以及各自的結束欄位。被拖的卡片若不在選取內，先單獨選取它。
- 拖到「全天」列：有時間的卡片移除時間，變成純日期；全天卡片拖進時間格：加上放下位置的時間。
- 月檢視放下：維持「只改日期、保留時間」，同樣支援多張一起移動。
- 多張寫入包在同一個 `trackSave` 內。

### 8.6 繁體中文（R0）

- 新增 `src/i18n/locales/zh-TW.ts`，`index.ts` 的 `zh-TW` 指向它；`zh` 維持簡體。
- 先以工具做簡繁轉換，再逐條人工改為台灣用語（视图→檢視、字段→欄位、文件→檔案等）。
- R1～R6 幾乎不新增介面文字；若有新增，同時補 `en` 與 `zh-TW`。

### 8.7 測試

- vitest：`calendar-utils.ts`（對齊、跨日位移、檔名清理、日期值格式）。
- 元件互動（選取、刪除、行內建立、拖曳）repo 沒有元件測試環境，不為此新增；每個步驟以 `npm run deploy` 在 Obsidian 實測，實測清單附在實作計畫。
